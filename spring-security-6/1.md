## Out of box
- Just by including spring security in pom gives protects all your endpoint with both formLogin() and httpBasic().
- Uses `Content Negotiation` to decide how to challenge the requester:
  - Form-Based for Browsers. `Accept: text/html` => redirected to /login. 
  - Basic Auth for Tools (like curl/postman). `Accept: */* or application/json` => 401 Unauthorized status with a `WWW-Authenticate: Basic header`.
- User: user, password: generated.
- Add user name and password in [application.yaml](src/main/resources/application.yaml) 
  - `Global AuthenticationManager configured with UserDetailsService bean with name inMemoryUserDetailsManager`
           
`User ----> Filter chain (including **security filter**) ---> Front Controller (Dispatcher Servlet) ---->App Controller`
- Session: JSESSIONID for each session

## user name and password
- `AuthenticationFilter` has `SecurityContext`
- talks to `AuthenticationManager` which in turn:
  - talk to `AuthenticationProvider` which in turn:
    - talk to `PasswordEncoder` & `UserDetailService` (has a method getByUserName() <-> DB )
